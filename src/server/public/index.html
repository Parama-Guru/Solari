How it works

Three steps, no local install.

01

Identify from the bytes

The extension is a hint, never the answer. Openable reads magic bytes, ZIP mimetypes and the named streams inside OLE2 containers, so a .doc renamed to .unknown still resolves to Word.

02

Open it on a throwaway machine

A Solari VM boots with LibreOffice, Inkscape, Ghostscript and ImageMagick already warm. Openable works down an ordered chain of strategies, from most faithful to most aggressive, until one produces a PDF that actually renders.

03

Prove it, then delete it

You get the PDF, the text and an image of every page as evidence. The report names the machine that held your file and the moment it was destroyed.

Openable

Your file is uploaded to a single-use virtual machine, opened there, and the machine is deleted when the run finishes or fails. Results are held in memory for 30 minutes and never written to disk. Tick keep nothing and even that is skipped.
