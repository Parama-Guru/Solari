Open a file nothing else will.

Drop in a document your computer refuses to open — an old Publisher or Works file, a CorelDRAW drawing, a spreadsheet that only opens through a repair prompt. It gets opened on a throwaway Linux machine, and you get back a readable PDF plus a picture of every page, so you can see it really worked.

Drop a file here, or click to choose Up to 25 MB. The machine that opens it is destroyed straight afterwards.
Your file is uploaded to a single-use virtual machine, opened there, and the machine is deleted when the run finishes or fails. Results are held in memory for 30 minutes and are never written to disk. Tick the box above and nothing is kept at all.
